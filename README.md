# Estudos

Exercícios e atividades desenvolvidos durante cursos técnicos — Java, Spring Boot e PHP.

## Exercícios de console (Java)

Programas simples de entrada/processamento/saída via terminal.

- **CalcularDadosdeCirculo**: calcula diâmetro, circunferência e área a partir do raio informado
- **CalcularVCobradoEstacionamento**: calcula o valor cobrado num estacionamento por hora, para múltiplos clientes em sequência
- **CalcularVvendaLoja**: calcula o valor de uma venda com opção de desconto à vista, parcelamento em 2x ou parcelado
- **DeterminarCodigoProduto**: classifica um produto (alimento perecível/não perecível, vestuário, higiene, limpeza) a partir de um código numérico

## APIs REST (Java + Spring Boot)

- **calculadora-api**: operações aritméticas básicas (somar, subtrair, multiplicar, dividir) via endpoints GET
- **livro-api**: CRUD de livros — cadastro, busca por ISBN/autor/título, listagem geral
- **moeda-api-3**: conversão e cotação entre moedas
- **produto-api**: cálculo de valor total de compra e preço de venda com taxa

## Sistemas web (PHP + MySQL)

CRUDs simples com formulário HTML + processamento em PHP.

- **Gerenciador de Clubes**: cadastro de clubes de futebol, com contagem de tricampeonatos
- **Gestor escolar**: cadastro e pesquisa de alunos e unidades curriculares
- **Registro de dados sobre projetos**: cadastro, contagem e exclusão de projetos
- **Processamento de vendas com PHP**: formulário de processamento de vendas
- **Processamento de vendas com comissão**: variação do anterior, com cálculo de comissão
- **controle de vendas Medicamentos**: controle de vendas de medicamentos
- **vetores compra medicamento**: formulário de compra online de medicamentos
